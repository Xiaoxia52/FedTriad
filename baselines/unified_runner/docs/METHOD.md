# FedRCA 方法说明

## 要解决的问题

不同医院即使使用同一网络，也会因为病种比例、成像风格和局部亚型不同而产生
客户端漂移。FedRCA 将这种异质性拆成三个层次：类别比例差异由双分类头处理，
类别内部的外观亚群由一次性像素聚类识别，训练过程中的编码器漂移由 RBF 空间
拓扑蒸馏约束。

## 一次性医院内像素分区

每个医院只使用自己的官方训练子集。对每个类别的全部 28 x 28 图像展平，使用
PCA 得到稳定的聚类坐标，再执行确定性 K-means。区域数由本院、本类样本量自适应
确定，上限为 4。聚类只在训练开始时执行一次；每个区域编号映射回原始样本索引，
后续不会用变化的网络特征重新聚类。

聚类结果、中心和原始图像均留在医院内。客户端只上传正常的模型参数，没有类别
图谱或聚类统计通信。一个样本的拓扑权重由其“类别—区域”支持度决定，小区域得到
温和增权，并在每个客户端内归一化为均值 1。

## 同构模型 RBF 空间拓扑蒸馏

第 r 轮开始时，服务器模型被冻结为教师，客户端从同一模型初始化为学生。同一张
本地图像分别通过二者，在 `pool2` 和 `relu3` 得到中间特征图。对每层特征自适应池化
到 7 x 7，将 49 个空间位置视为图节点，通道向量归一化后计算两两平方距离：

`P(i,j|F) = softmax_j(-||f_i-f_j||^2 / sigma)`

教师和学生分别得到 49 x 49 的关系概率图，优化教师到学生的 KL 散度。两个层级各有
一个可学习带宽，带宽随共享编码器一起聚合。分类 logits 和任何分类头都不参与 RBF
计算，因此对齐的是网络内部空间关系，不是类别中心、聚类中心或分类输出。

类别—区域权重作用于每个样本的拓扑 KL，使少数病理亚群不会被同类主流外观淹没：

`L_topo = sum_b w_b KL(P_T^b || P_S^b) / sum_b w_b`

## 保留的 V2.1 双头机制

- 全局分类头使用普通交叉熵训练，与编码器一起按客户端样本量完整聚合，可直接服务
  新医院和官方测试集。
- 每个医院保留不上传的私有分类头，使用本院类别频率的温和重加权交叉熵。
- 私有头读取 `detach` 后的特征，只更新私有头自身，不会稀释或扭转共享编码器与全局
  分类头的梯度。
- 系统分别按客户端验证 Macro-F1 保存个性化检查点，按官方验证 Macro-F1 保存全局
  检查点；测试集只在训练结束后评估，不参与选择。

完整训练目标为：

`L = L_global_CE + lambda_p L_private_CE + lambda_t(r) L_topo`

前 5 轮只训练分类目标，随后 10 轮把拓扑系数线性升至 0.1，以免随机初始化阶段的
关系图干扰分类学习。

## 消融定义

- `no_rbf`：保留像素区域与双头，只去掉拓扑蒸馏。
- `no_regions`：拓扑蒸馏中所有样本权重为 1。
- `random_regions`：保持相同区域数，用固定随机分区替代 K-means。
- `single_region`：每个类别只有一个区域，只保留类别级平衡。

## 边界

当前医院由公开数据的 Dirichlet 划分模拟，不是真实患者级医院划分。方法没有实现
差分隐私或安全聚合，不能声称形式化隐私保证。两个创新是否带来稳定增益，必须由
三个数据集、两个异质性强度和三个随机种子的主实验与消融共同证明。
