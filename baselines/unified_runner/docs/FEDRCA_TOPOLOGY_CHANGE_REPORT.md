# FedRCA 拓扑版修改报告

## 参考实现核对

- Lite-MyoNet 的关键思想是教师与学生中间特征的节点两两距离，经 Gaussian RBF
  和行 softmax 转成概率拓扑，再用教师到学生的 KL 做结构蒸馏。
- SAIL-DM/CA-CDM 的 K-means 用于一次性固定数据分区：类内像素描述先聚类，区域
  成员随后映射回完整样本，不随训练特征反复变化。

## 已删除的错误版本组件

- 基于训练特征反复执行的类内 K-means。
- 客户端上传区域均值、方差、支持度并在服务器持久保存的类别图谱。
- 样本到类别锚点的 RBF、区域几何中心损失以及 RBF 分类器融合推理。

上述组件把“对齐模型拓扑”误写成了“对齐数据或聚类中心”，不再属于当前方法。

## 当前实现

1. 每个医院、每个类别使用全部原生 28 x 28 训练图像，一次性拟合像素
   PCA+K-means；固定区域编号映射回每个原始样本。
2. 第 5 轮后，轮前全局同构网络作为冻结教师，当前客户端网络作为学生。
3. 同一图像在 `pool2` 与 `relu3` 的完整中间特征图上构建 7 x 7 空间节点关系图。
4. 两层 RBF 拓扑使用独立的可学习带宽，优化区域平衡的教师到学生 KL。
5. 保留 V2.1 的完整全局分类头、停止梯度的类别平衡私有头和全局/个性化双检查点。
6. 最终全局推理只使用正常全局分类头，没有融合权重和额外 RBF 推理开销。

## 实验身份

主配置仍是三个 28 x 28 数据集、11 个方法、两个 Dirichlet alpha、三个 seed、
300 轮。学习率在第 180 和 255 轮衰减。新结果写入：

`runs/main_3datasets_11methods_300r_topology_rbf`
